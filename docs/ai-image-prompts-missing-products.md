# AI image prompts — 11 products with no photography (v2, per-category)

**v2 fix:** the previous version baked a **ring box** into the shared style block, so
ChatGPT placed necklaces, bracelets and studs inside a ring box. Wrong. Each category now
has its **own presentation surface**. The *look* (black props, gold "JS" monogram, dark
polished stone, cream-rose + gold bokeh, same lighting) stays consistent so the set matches —
only the object the jewellery sits on/in changes.

Generate in ChatGPT (GPT Image). One prompt per angle, per product.

---

## HOW TO USE

Every prompt = **LOOK BLOCK** + **PRESENTATION line (per category)** + the piece description.
Paste the LOOK BLOCK first, then the correct PRESENTATION line for that category, then the
angle prompt. Swap the metal phrase for each of the 3 metals.

### LOOK BLOCK — paste at the top of every prompt

```
Ultra-photorealistic luxury jewelry product photograph, shot on a 100mm macro lens,
studio lighting with a soft large key light and controlled specular highlights.
Colour palette: black, warm gold, champagne, white diamond brilliance. Behind the subject,
a softly blurred dark polished-stone surface with a single cream rose and warm gold bokeh
highlights out of focus. Crisp faceting, realistic dispersion and light return, true-to-life
metal. No plastic or CGI look, no text or watermark, no brand logo except where noted on a
display card. Square 1:1, 4K, tack-sharp on the jewellery.
```

### PRESENTATION line — pick ONE per product, by category

| Category | PRESENTATION line to paste |
|---|---|
| **Ring** (solitaires) | `The ring stands upright in the slot of an open black leather ring box; the box's inner lid is embossed in warm gold with a "JS" diamond monogram above the word "JEWELSTONE".` |
| **Stud earrings** | `The pair of studs is pressed into a black suede stud-earring display pad (a flat black cushion with two small holes), posts hidden, both studs level and side by side. No ring box. A slim black display card behind is embossed in gold with a small "JS" monogram.` |
| **Tennis / fancy necklace** | `The necklace is draped over a matte-black velvet neck-form display ramp (a curved half-bust stand), following the curve so the full line hangs naturally as it would on a neck. No box. A black backdrop card behind carries a small gold "JS" monogram. Do NOT place it inside a ring box.` |
| **Tennis bracelet** | `The bracelet is wrapped once around a black velvet bracelet display roll (a horizontal padded cylinder), forming a clean circle so the full line of diamonds is visible. No ring box. A black card behind carries a small gold "JS" monogram.` |

> The "with Model" angle ignores both the LOOK BLOCK background and the PRESENTATION line — it
> uses the model wording given in each product instead.

### METAL phrase — generate each studio angle 3×

| Suffix | Phrase |
|---|---|
| `WG` | `14K white gold, bright rhodium-white metal` |
| `YG` | `14K yellow gold, warm rich yellow metal` |
| `RG` | `14K rose gold, soft pink-copper metal` |

**File naming:** `<Product> <angle> <METAL>.png` — e.g. `20ct stud front WG.png`.

## Negative prompt (every generation)

```
ring box for a necklace, ring box for a bracelet, ring box for studs, wrong display, text,
watermark, brand name other than the display card, cartoon, illustration, CGI plastic look,
oversaturated colour, blurry facets, malformed prongs, extra fingers, distorted hand anatomy,
asymmetric pair, cluttered background, harsh flash
```

## Delivery

Per product: 3 metals × 3 studio angles = 9, plus 1 model = **10 images**.
Eleven products = **110 images**. Folder per product; I convert to `.webp`, build the
`mediaByMetal` sets and wire into `data/products.ts`.

## If you must keep it simpler

Minimum viable = **1 metal (WG) × front + close-up + model = 3 images per product**. That is
enough for me to publish a clean product page; the other metals/angles can follow later.
